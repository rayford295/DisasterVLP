# Figures

This directory contains all figures and visual materials used in the **DisasterVLP** project, including conceptual diagrams, framework illustrations, and experimental workflow visualizations.

These figures are primarily used to support:
- Model design explanation,
- Large Vision–Language Model (VLM)–based disaster reasoning,
- Experimental setup and multi-phase pipeline illustration,
- Result interpretation and qualitative analysis.

## 📁 File Overview

The figures in this folder include (but are not limited to):

- **Overall Framework**
  - `overall framework.drawio.png`  
    High-level overview of the DisasterVLP architecture and processing pipeline.

- **Multi-Phase Workflow**
  - `phase2.drawio.png`  
  - `phase3.drawio.png`  
    Visual illustration of different stages in the DisasterVLP framework, including perception, reasoning, and assessment phases.

- **Labeling & Output Illustration**
  - `label result.drawio.png`  
    Examples of disaster-related labels or structured outputs generated by the vision–language model.

- **Study Area & LLM Integration**
  - `llm_studyarea.drawio.png`  
    Conceptual diagram illustrating how study area information and spatial context are incorporated into large language or vision–language models.

All figures were created using **draw.io** and exported as PNG files for compatibility with papers, slides, and documentation.
